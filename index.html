Як підключити цей файл до Telegram за 3 хвилини

Оскільки вся логіка генерації TOTP-кодів вже вбудована у цей один HTML-файл, вам достатньо один раз завантажити його на безкоштовний хостинг (GitHub Pages або Cloudflare Pages) і прив’язати до бота в @BotFather.

1

Завантажте цей файл на GitHub Pages

Збережіть цей файл під назвою index.html, завантажте у безкоштовний публічний репозиторій на GitHub і увімкніть Settings → Pages. Ви отримаєте посилання виду https://ваш-нік.github.io/2fa/.

2

Створіть Mini App у @BotFather

Відкрийте @BotFather у Telegram, відправте команду /newapp, оберіть вашого бота, вкажіть ваше посилання з GitHub Pages та задайте коротке ім'я додатка (наприклад, totp).

3

Надсилайте персональні посилання

У вкладці «База ключів» додайте ключ нового клієнта та скопіюйте готове повідомлення. Коли клієнт натискає на посилання у повідомленні, прямо в Telegram відкривається вікно з його живим 2FA-кодом!

Бонус: Як надсилати красиву WebApp-кнопку прямо під повідомленням бота

Якщо ви хочете, щоб клієнт натискав не на текстове посилання, а на інлайн-кнопку під повідомленням

from aiogram import Bot, Dispatcher, types
from aiogram.types import InlineKeyboardMarkup, InlineKeyboardButton, WebAppInfo

# Кнопка передає секретний ключ клієнта прямо у ваш Mini App:
def get_2fa_keyboard(secret_key: str, label: str = "Account"):
    url = f"https://my-shop.github.io/2fa/?mode=client&secret={secret_key}&label={label}"
    return InlineKeyboardMarkup(inline_keyboard=[[
        InlineKeyboardButton(text="🔐 Показати живий 2FA-код", web_app=WebAppInfo(url=url))
    ]])
